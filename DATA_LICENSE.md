# Licenca dos Dados Meteorologicos

Os dados meteorológicos utilizados e exibidos neste projeto são consumidos a partir da API do **OpenWeather**. 

De acordo com as diretrizes oficiais do provedor, os dados dos planos gratuitos e de autoatendimento são fornecidos sob as seguintes licenças de dados abertos:

* **Conteúdo e Mapas:** [Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)](https://creativecommons.org)
* **Bases de Dados Brutas:** [Open Database License (ODbL)](https://opendatacommons.org)

## Termos Importantes (ShareAlike)
Como este projeto utiliza dados sob a licença *ShareAlike* (CompartilhaIgual), qualquer modificação, enriquecimento ou redistribuição pública das bases de dados meteorológicas derivadas deste aplicativo também deve ser compartilhada sob as mesmas licenças (CC BY-SA 4.0 e ODbL).

Para mais detalhes sobre as regras comerciais e termos de serviço, consulte os [Termos e Condições do OpenWeather](https://openweathermap.org).
