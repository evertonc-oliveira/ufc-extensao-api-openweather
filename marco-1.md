## Campo 1 — O que funciona hoje

1. Rodar `python clima.py` no terminal e receber na tela a temperatura (ex: "30.05°C") e a condição climática (ex: "Céu limpo") atual de Fortaleza, consumindo a API da OpenWeather.
2. Abrir o arquivo `clima.py` em um editor de código, alterar os valores das variáveis `lat` (latitude) e `lon` (longitude) e receber o clima correspondente a qualquer outra localidade do mundo.
3. Abrir o arquivo `README.md` na raiz do repositório e ler o passo a passo completo (desde a instalação do Python até a geração da API Key) para reproduzir o código localmente.
